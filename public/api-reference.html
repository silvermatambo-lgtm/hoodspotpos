REST API v1

Use the /api/v1/ prefix on this deployment. Check API and database health.

Sign in and make a request

The API uses an HttpOnly session cookie. Keep the returned cookie in your client and include it with later requests. Sign in with owner / Owner@2026 or cashier / Till@2026. Omit the workspace code to create a new workspace, or pass your existing code to join it. Demo data only.

POST /api/v1/session
Content-Type: application/json

{"username":"cashier","password":"Till@2026","workspace":""}

Get the product ID and price from GET /api/v1/catalog. Amounts are integer USD cents. Generate a fresh UUID v4 for each new sale and send the exact same payload if retrying.

POST /api/v1/sales
Content-Type: application/json

{
  "id": "d91f5df2-426b-49bb-8fb1-1971a4f2a9ba",
  "items": [{"id":"<product UUID>","qty":1,"price":200}],
  "payment":"cash",
  "tendered":200,
  "soldAt":"<current ISO 8601 timestamp>"
}

Resources

Method and resourceAccessWhat it does
GET /healthPublicService and database status
POST /sessionPublicAuthenticate and set session cookie
GET /session · DELETE /sessionSigned inRead or end the session
GET /catalogSigned inActive products, retail prices, stock and alert levels. No costs
GET /sales · POST /salesSigned inRead own receipts or record a sale. Accepted payment values are cash, ecocash and card. No payment processing
GET /report?range=todayOwnerSales, gross profit, best sellers and payment mix. Range can be today, week or month
GET /stockOwnerInventory, cost and stock activity
POST /products · PATCH /products/{id}OwnerCreate or edit products. Fields are name, category, price, cost, low, active, and opening stock on create
POST /stock/{id}/adjustmentsOwnerChange stock. Fields are delta (signed units) and reason
GET /staff · POST /staff · PATCH /staff/{username}OwnerList, add and update cashier access. Use username, name, password on create, and name, active, optional password on update

Expected responses include 401 for expired or missing sign-in, 403 for role restrictions, 409 for stock or price conflicts and 429 for rate limits.
